Connect to GitHub

LitReview stores your papers in a JSON file inside a GitHub repository, enabling real-time collaboration with your colleagues.

Step 1 — Create a GitHub repo
Create a new repo (e.g. my-literature-review) on GitHub. It can be private.
Add a file called papers.json with content [].
Step 2 — Generate a Personal Access Token
GitHub → Settings → Developer settings → Fine-grained tokens.
Grant Contents: Read and Write on your repo.
Step 3 — Share this HTML file
Deploy to GitHub Pages (Settings → Pages → from branch main) and share the URL with your collaborator. You can both use the same token or each generate their own.
